# GitHub Repository

Repositori ini berisi proyek Flutter **Aplikasi Wisata Indonesia** untuk Tugas Pemrograman Mobile Bab 7 - Routing & Navigasi.

## Quick Start

```bash
git clone <url-repo-ini>
cd navigasi_wisata
flutter pub get
flutter run
```

## Daftar File Penting

- `lib/main.dart` - Konfigurasi MaterialApp + routing
- `lib/pages/home_page.dart` - Beranda (GridView 4 menu)
- `lib/pages/pantai_page.dart` - Halaman Pantai Kuta Bali
- `lib/pages/gunung_page.dart` - Halaman Gunung Rinjani
- `lib/pages/budaya_page.dart` - Halaman Tari Saman
- `lib/pages/kuliner_page.dart` - Halaman Rendang
- `lib/pages/detail_wisata_page.dart` - Halaman Detail Wisata (penerima parameter)

## Versi Flutter

Minimum: Flutter 3.5.0 / Dart 3.5.0
